# Creating logo arts

Bootstrap banners in this folder are generated with [Text to ASCII Art](https://www.asciiart.eu/text-to-ascii-art).

Use the same settings for every product so widths stay consistent:


| Setting           | Value  |
| ----------------- | ------ |
| Font              | Doom   |
| Border            | Stars  |
| Horizontal Layout | Fitted |
| Vertical Layout   | Normal |
| Width             | 114    |
| V. Padding        | 1      |
| H. Padding        | 5      |
| Output Font       | Monaco |
| Output Size       | 22pt   |


Copy the generated art into the matching `.txt` file (no extra blank lines around the border).


| File                        | Source text             |
| --------------------------- | ----------------------- |
| `blockera.txt`              | `Blockera Builder`      |
| `blockera-pro.txt`          | `Blockera Pro`          |
| `blockera-one.txt`          | `Blockera One`          |
| `blockera-site-toolkit.txt` | `Blockera Site Toolkit` |
